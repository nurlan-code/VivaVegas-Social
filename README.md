## 📝 Customization

### Changing Colors
All colors are defined in CSS variables at the top of each file:
```css
:root {
    --vegas-red: #DC143C;
    --vegas-gold: #FFD700;
    --vegas-dark-gold: #B8860B;
    --vegas-black: #0A0A0A;
    --vegas-dark: #1A1A1A;
}
```

### Adding Content
Each page is self-contained with inline CSS and JavaScript. Simply edit the HTML content within each file to customize.

### Modifying Animations
Animation keyframes are defined in the `<style>` section of each page. Adjust timing, duration, and effects as needed.
